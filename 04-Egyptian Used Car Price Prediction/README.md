# 🚗 Egyptian Used Car Price Prediction

A Machine Learning project for predicting the prices of used cars in Egypt using **Linear Regression**.

The project uses real used-car data collected from the Egyptian market and includes data preprocessing, feature engineering, categorical encoding, feature scaling, model training, and a **Streamlit web application** for price prediction.

---

## 📌 Project Overview

The goal of this project is to build a regression model that predicts the expected price of a used car based on its characteristics.
